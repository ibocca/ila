# GitHub practice repo - Visual Design Team

This repo is only for practising GitHub. **Everything in it is fake**: the product "DEMO Board X1" does not exist. Break things, that's the point.

## What's inside

| Folder / file | What it is |
| --- | --- |
| `README.md` | This page. GitHub shows it automatically below the file list. |
| `images/banner.png` | Launch banner, version 1 (teal) |
| `images/product-render.png` | Approved product render |
| `texts/product-description.md` | Product copy for the website |
| `texts/launch-checklist.md` | Launch tasks for the design team |

## What you'll practise

1. Edit a file and upload it to a new branch
2. Review your pull request and merge it into `main`
3. Open a ticket (issue)
4. Overwrite a file in `main` by mistake
5. Restore `main` to the previous version

## Rules of this repo

- Never work directly on `main`: create a branch, open a pull request, then merge.
- Write commit messages that say what changed, e.g. "Update banner to v2".
- Keep file names exactly as they are when you replace a file.
